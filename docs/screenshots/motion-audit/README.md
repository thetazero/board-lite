# Motion audit (#169)

Evidence for the audit of jerky animations and hard cuts on the TV and the phone, written up on issue #169. The strips (`*.strip.jpg`) label each frame with its time from the moment; the GIFs replay the frames as painted. `report-*.md` are `npm run motion`'s reports for the two runs (a whole game; 12 minutes with `--flat`). They name clips that stay in the run's folder, `~/.cache/board-lite/motion/`, and aren't kept here. The dragon take-off and landing strips are staged shots, with the board clock stepped through the first dragon's flight.
